# Security Policy
## Supported Versions
Only the most recent minor release receives security updates.
| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅         |
| < 1.0   | ❌         |
## Reporting a Vulnerability
If you discover a security vulnerability, please **do not** open a public
GitHub issue. Instead, send an email describing the issue to:
**allarayzer@gmail.com**
Please include:
- A description of the vulnerability
- Steps to reproduce
- The version affected
- Any suggested mitigations
You can expect an initial response within 7 days. If the issue is confirmed,
a fix will be prepared and coordinated disclosure arranged.
## Scope
This project is a research prototype; it is **not recommended for direct
deployment in safety-critical industrial systems** without independent
validation and hardening. Users integrating any component into production
systems bear responsibility for appropriate safety review under the relevant
regulatory framework (e.g., IEC 61508, ISO 13849).
